# 论文3 LaTeX 编译说明

论文3.tex与论文3.docx由同一份_build/src源稿生成。所有内容修订应先改源稿，再运行_build/mk.py；不要仅修改单一成稿。

## 编译

在本目录使用XeLaTeX连续编译两遍：

```text
xelatex -interaction=nonstopmode -halt-on-error 论文3.tex
xelatex -interaction=nonstopmode -halt-on-error 论文3.tex
```

当前PDF为38页，编译通过；无缺字及Overfull框。

正文参考文献直接排版，不需运行BibTeX；references.bib保存同一批10项书目元数据。正文引用以\textsuperscript呈现，文献条目号不设上角标。

figures目录包含12张实际引用图片。fig11.png对应正文图6，fig12.png对应正文图12；文件编号与出现顺序不同不影响引用。新增图的数据见../_build/figure_data。

Word采用可编辑OMML公式；生成器依赖Office的MML2OMML.XSL和Python的latex2mathml、python-docx。

文件目录说明见../交付说明.md；文献附件集中于../参考文献。
