# 论文3 LaTeX 编译说明

## 一、目录内容

```
论文3_LaTeX/
  论文3.tex          主文件（由 _build/mk.py 自动生成，不要手改）
  论文3.pdf          已编译好的成品（38 页）
  references.bib     参考文献 BibTeX（6 条，均经核实）
  figures/           正文引用的全部插图 fig01—fig10.png（共 10 张）
  编译说明.md        本文件
```

`figures/` 中只保留 `论文3.tex` 实际引用到的图。正文用 `\graphicspath{{figures/}}` 定位，
因此在 `论文3_LaTeX/` 目录下直接编译即可，无需把图片复制到别处。

## 二、编译方式

必须用 **XeLaTeX**（文档为 `ctexart` 且含中文，pdfLaTeX 编译不过）：

```bash
cd 论文3_LaTeX
xelatex -interaction=nonstopmode 论文3.tex
xelatex -interaction=nonstopmode 论文3.tex    # 第二遍，生成正确的页码与目录
```

两遍即可，不需要 bibtex（正文的参考文献是手写列表，`references.bib` 仅作条目存档，
未在主文件中 `\bibliography` 调用，避免引入 `natbib`/`biblatex` 的额外依赖）。

## 三、环境要求

- TeX 发行版：MiKTeX 或 TeX Live（本轮在 MiKTeX 25.12 上两遍编译通过）。
- 除标准宏包外，中文支持需要以下两个包，若缺失请先安装：
  - `ctex`（提供 `ctexart` 文档类）
  - `zhnumber`（ctex 的依赖，用于中文数字）
  - MiKTeX 下可执行：`mpm --install=ctex` 与 `mpm --install=zhnumber`
- 主文件显式加载的宏包：`amsmath, amssymb, bm, graphicx, booktabs, longtable, array,
  geometry, caption, float, hyperref`，均为 TeX Live / MiKTeX 的标准组成部分。

## 四、编译结果自检（本次实测）

| 项目 | 结果 |
|---|---|
| 页数 | 38 |
| 缺字（`There is no ... in font`） | 0 |
| 报错（`! ...`） | 0 |
| 未定义引用 / 缺图 | 0 |
| Overfull hbox | 6 处，最大 36.0pt |
| Overfull vbox | 2 处（54.4pt、71.3pt） |

三处 36.0pt 的 Overfull hbox 来自四列以上的宽表格，已用 `\resizebox{\textwidth}{!}{...}`
压到版心宽度，超出的 36pt 是 `\resizebox` 盒子的固有宽度误差，不影响可读性。
两处 Overfull vbox 出现在插图页，属于浮动体排布的正常现象。

## 五、常见问题

**`File 'ctexart.cls' not found`**
未装 `ctex` 宏包，见第三节。MiKTeX 也可以打开
`MiKTeX Console → Packages` 搜索 `ctex` 安装。

**`File 'fig01.png' not found`**
编译时的工作目录不对。必须在 `论文3_LaTeX/` 目录下执行 `xelatex 论文3.tex`；
`\graphicspath` 用的是相对路径 `figures/`。

**表格里的中文没居中**
三列表统一使用自定义列型 `C{宽度}`（`>{\centering\arraybackslash}p{宽度}`），
定义在主文件导言区。若自行改动表格列数，注意列型要与列数匹配。

## 六、与 Word 版的一致性

`论文3.docx` 与 `论文3.tex` 由同一份源文件（`../_build/src/*.md`）经 `../_build/mk.py`
同时渲染生成，因此章节结构、公式、表格数值、图注与结论完全一致，只有分页与断行不同。
**不要单独修改 `论文3.tex` 或 `论文3.docx`**，任何内容改动都应改 `_build/src/` 下的源文件后重跑：

```bash
cd ../_build
python gen_tables.py   # 从冻结 CSV 重新生成 _tables/*.md
python mk.py           # 同时重新生成 论文3.tex 与 论文3.docx
```

`mk.py` 生成 Word 公式依赖本机 Office 的 `MML2OMML.XSL`
（默认路径 `C:\Program Files\Microsoft Office\root\Office16\MML2OMML.XSL`）；
若该路径不同，需修改 `mk.py` 顶部的 `XSL` 常量。
