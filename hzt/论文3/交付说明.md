# 论文3交付文件

- `论文3.docx`：Word版本，可编辑公式。
- `论文3_LaTeX/`：LaTeX源文件、PDF、书目元数据和12张正文图片。
- `参考文献/`：实际引用的8份PDF，文件前缀与正文文献编号一致；清单记录页数与SHA256。
- `_build/src/`、`_build/mk.py`：Word与LaTeX共用的编辑源稿和生成器。
- `_build/figure_data/`：正文新增两图的绘图数据。

文献[3]《运筹学教程》和[4]《数学模型》为正式引用教材，未提供PDF附件。候选建议、临时核查脚本、预览、旧备份及编译辅助文件已清理至回收站。

继续编辑时先修改`_build/src`，再运行`python _build/mk.py`同步生成Word和LaTeX。PDF编译方法见`论文3_LaTeX/编译说明.md`。
