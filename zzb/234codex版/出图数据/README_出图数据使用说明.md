## 最重要的时间与单位约定

1. **A和主C是自然日物理轴。**`t=1`表示当日00:00—00:10，`time_end=00:10`；`t=144`表示23:50—次日00:00，`time_end=00:00+1`。
2. A/C的`physical_slot0=t-1`。主C的`slot=t`也从1开始，和A按`date,t`直接连接；不能把它当旧程序的零基计划下标。
3. 自然日首段来自前一日计划第144段，因此A/C额外给出`decision_date,plan_slot0`。自然日t=1对应前日计划下标143；自然日t=2对应当日计划下标0。
4. **真正的计划日144段另存`*_计划日144段.csv`。**其中`j=1`为00:10—00:20，`j=144`为次日00:00—00:10。最后一行的`execution_date`是次日。该表不可按同日同下标直接连接A。
5. A的`x_plan_kwh`是该物理段实际生效的最终承诺（Q3/Q4-3为x3）。首版与最终对比用A的`x0_kwh,x3_kwh`或主C的同名列。
6. 所有`*_kw`是功率，`*_kwh`是十分钟电量。与kW曲线同轴比较时，购电/紧急购电功率应为电量乘6，不能直接把kWh曲线与kW曲线混画。
7. B所有主要购电量、费用、流量和修订量均按自然日00:00—24:00统计，包含前日末承诺、排除本计划日跨入次日的第144段。`decision_day_planned_purchase_kwh`单独保留本次计划行144段合计，不能替代自然日合计。
8. A的`L_fc_kw,P_fc_kw`重建本版执行窗口使用的已发布预测；`L_commit_fc_kw,P_commit_fc_kw`表示有效购电承诺形成时的预测，首段用前一日末次决策的次日首段预测。不得把这两类预测混为同一个发布时刻。
9. 日内发布时刻为00/06/12/18；06/12/18之后的物理段使用相应更新预测。储能实时反馈与末点实际值的解释沿用本版执行模型，不意味着计划提前知道未来实测。
10. 日SOC范围包括00:00初值和全部144个段末；24:00值是自然日最后段末，并非计划第144段之后。没有SOC日循环相等约束。

## 字段与诊断说明

- 文件名前缀固定为`Q2_reserve-mpc`、`Q3_exact-greedy`、`Q4-2_reserve-mpc`、`Q4-3_exact-greedy`。
- 需求中的A字段全部提供；新增时间、价格、首末SOC及承诺预测字段用于消除歧义。
- B提供需求中的费用、修订量、流量及储备字段。单阶段没有修订，所以这些修订量为数学上真实的0，而非缺失值填0。
- `reserve_kwh`为午夜计划输入的原始R；内核将储备上限截为4800kWh，故另给`reserve_effective_kwh`。四阶段的各时刻R单列；日累计残差窗口从该次决策后的当日段算到24:00，不提前计入次日首段。
- `chain_misprice_yuan`在本交付中定义为冻结grid费用减去独立链式费用公式的残差；`cost_identity_residual_yuan`是总费用减grid费用减紧急费用。它们是结算恒等式检验，不是独立因果性检验，也不是重构旧版近似目标误价。
- 月度逆行比例同时提供“逆行段/全部物理段”和“逆行段/出现下调的段”，避免分母混用；单阶段分母为0时比例记0并保留分母字段。
- 朴素基准使用前一自然日同一物理段实际负载/光伏，不使用未来数据。误差定义为实际减预测；分位带为同一物理t跨正式期日期的样本分位。
- G的紧急电量比例分母为负载总电量；CVaR95为不低于样本95%分位的日费用均值（含并列阈值样本）。
- G中`校正后总费用=total_cost_yuan`，`correction_applied_yuan=0`。本版实际年终SOC已经6000，不能再加减储能残值或凭此修改冻结费用。
- V1同时列334天和365天。画图时应按`period`筛选，而不能把同一问题两行当两个模型。

## F的严格解释：不能强行当成三项纯因果贡献

- C0：全知物理LP松弛下界，允许事先知道所有实际负载、光伏、电价，不包含承诺调整附加费。它是对可实现模型的乐观下界，不是可执行策略。
- 334天版C0的2月1日00:00初始SOC明确放松为10800，以形成不受各模型1月预运行状态差异影响的公共下界；因此C1−C0也包含初始资源放松和边界影响，不能全称“决策结构损失”。
- 365天版C0从1月1日6000开始，年终6000，保留年初零承诺；仍是去掉信息限制、链式费用限制后的物理LP松弛。
- C1：保留本版决策框架、执行规则和年终保护，但人为给出完美负载、光伏、电价；次日首段也使用oracle实际值。
- C2：同样框架、保留因果负载/光伏预测，只把电价设成完美。固定电价的Q2/Q3中C2=C3，无需另跑。
- C3：本版已冻结最终费用，直接复用，不重跑。
- F单位为万元，G为元。F同时生成334天和365天，画差距必须选一致期间。
- C1/C2来自保留水值、储备和执行启发式的oracle对照，不是决策结构的严格最优值。因此C0≤C1≤C2≤C3不保证成立；脚本保留带符号差值和`monotone_ladder`，不把负差改0、不排序、不伪造单调性。非单调时应画瀑布/带符号差值，不能强画全正堆叠柱。
