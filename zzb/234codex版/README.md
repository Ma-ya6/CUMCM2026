# 234codex版

以234一次优化版计算内核及获准读取的直接依赖源码为基础，不使用其他版本的结果。
共享计算入口为 `run_year.py`；项目管理入口为 `python project.py`，分问题入口调用同一内核。旧opt脚本仅保留为来源代码，不用于本版运行。

## 按一次优化版结构整理的交付目录

- `问题2最终模型/`、`问题3最终模型/`、`问题4最终模型/`：方法说明、模型评价、全年运行入口和已核验结果副本。
- `答案总结/`：本版结果说明；`最终结果汇总.md`：四模型费用。
- `verify/`：核验入口；`audits/`：详细诊断、D/F补算汇总及证据。
- `results/`：唯一主结果；根目录`frozen_numbers.json`：核验后复制的冻结数字。
- `出图数据/`：84份CSV、D/F实验及一键脚本；`cache/`、`deps/`、`opt/`：共享依赖和计算来源。
- `封版核验.md`、`最终文件清单.json`：当前交付状态和SHA-256清单，不代表竞赛论文已最终获批。

## 运行

```powershell
python project.py --help
python project.py run --problem Q2
python project.py run --problem Q4
python project.py smoke --problem Q2 --days 2
python project.py verify
python project.py verify --deep
python project.py export
python project.py package
```

`run`会覆盖指定模型的主结果；`smoke`写入独立临时目录，不破坏全年结果。重算后执行`package`刷新交付副本、汇总、冻结数字和清单。
打包不改算法、不重新跑全年优化；核验中的时间回归只在临时目录做短样本模拟。分问题`一键全年计算.cmd`会重算后打包，根目录`一键核验与打包.cmd`只核验和打包。

## 当前时间与模型口径

- 原始附件数组保持自然日物理轴；计划144段覆盖00:10—次日00:10。
- 00:00仅以预测首段后的SOC制定计划，实际首段执行前一日末承诺。
- 06/12/18时调整物理下标36/72/108，即计划下标35/71/107。
- 问题2只使用附件1、2；问题3增加附件3；问题4增加附件4。
- 附件3按发布后整点预测解释，右端点线性插值，锚点仅用已到达实测；零值掩码是历史支持窗口校正，不是严格物理夜间判据。
- 次日首段负载及波动电价使用当前可得同钟面预测，不读取次日预测数组；该段光伏置零。
- 年初首段购电承诺为零，初始SOC6000kWh；1月预运行连续传递到2月。
- 无日终SOC相等约束。12月31日自然日24:00实际SOC回到6000kWh，跨年计划末段不计入2025实际费用。
- 年末执行采用明确的目标可达保护，必要时紧急购电充电，计入真实费用；不通过残值校正代替年终约束。

结果分别报告365天自然年实际费用及2月1日—12月31日334天正式期实际费用。
预测缓存只保存本版从原始附件重建的结果；不复制旧预测缓存、旧费用或旧结果。
