# 234codex版

以234一次优化版计算内核及获准读取的直接依赖源码为基础，不使用其他版本的结果。
唯一正式入口为 `python run_year.py`，旧opt脚本仅保留为来源代码，不用于本版运行。

- 原始附件数组保持自然日物理轴；计划144段覆盖00:10—次日00:10。
- 00:00仅以预测首段后的SOC制定计划，实际首段执行前一日末承诺。
- 06/12/18时调整物理下标36/72/108，即计划下标35/71/107。
- 问题2只使用附件1、2；问题3增加附件3；问题4增加附件4。
- 附件3按发布后整点预测解释，右端点线性插值，锚点仅用已到达实测；夜间按物理规则置零。
- 次日首段负载及波动电价使用当前可得同钟面预测，不读取次日预测数组；该段光伏置零。
- 年初首段购电承诺为零，初始SOC6000kWh；1月预运行连续传递到2月。
- 无日终SOC相等约束。12月31日自然日24:00实际SOC回到6000kWh，跨年计划末段不计入2025实际费用。
- 年末执行采用明确的目标可达保护，必要时紧急购电充电，计入真实费用；不通过残值校正代替年终约束。

结果分别报告365天自然年实际费用及2月1日—12月31日334天正式期实际费用。
预测缓存只保存本版从原始附件重建的结果；不复制旧预测缓存、旧费用或旧结果。
