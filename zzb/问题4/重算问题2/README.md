# 问题4：波动电价下重算问题2

问题四要求把电价由附件1的单条固定日内曲线换成附件4的逐日逐时段波动电价，重算问题2。
本目录是其中的"重算问题2"部分，输出 `results/result4-2.xlsx`。

模型沿用问题2最终版的三层结构（季节水平预测＋因果分位数安全余量＋确定性储能LP），
唯一差别是电价通道。

## 信息集：三条通道全部因果

| 对象 | 第 d 天 0:00 可用信息 |
| --- | --- |
| 负载、光伏 | 仅 $j<d$ 的历史实际值，走原因果集成预测 |
| 电价 $c_{d,t}$ | **不可预知**，当天 144 时段电价由 $j<d$ 的历史实际电价因果预测，记 $\hat c_{d,t}$ |
| 结算 | 计划购电按当天**实际**电价 $c_{d,t}x_{d,t}$、紧急购电按 $5c_{d,t}e_{d,t}$；LP 目标与储能套利用预测电价 $\hat c_{d,t}$ |

- 1 月为预测预热与储能状态递推期，2 月 1 日–12 月 31 日为正式费用评价期。
- 第 0 天用附件1的单条电价曲线作冷启动先验，与 `initial_load`/`initial_pv` 同构。
- 电价不进入季节校正管线（光伏有效窗口与日电量水平因子是光伏/负载专用的物理量）。
- 与问题2一致：不使用附件3的光伏预报，那是问题3的机制。

## 风险分位数 $q=0.80$：与电价无关

单时段的期望费用为 $E\big[c\,x+5c\,(N-x)^+\big]$，$N$ 为净负荷。一阶条件为

$$P(N>x)\,E[c\mid N>x]=E[c]/5 .$$

由于计划购电与紧急购电**按同一时刻的同一个 $c$ 结算**，$c$ 在临界比中约去，
报童临界比为 $4c/(4c+c)=0.80$。该值因此与电价的**取值、分布、是否可预知**均无关，
是事前给定的理论值，不由任何评价期回测挑选；`results/风险参数敏感性.csv` 中的
$q$ 网格只作事后对照。

（严格地，上式在 $c$ 与净负荷误差独立的条件下精确；本文按全局 $q=0.80$ 处理，
不引入按季节或电价高低分档的分位数，以避免任何样本内选择。）

## 代价归因（论文第 8 章）

以下对照全部使用同一套因果负载/光伏预测与同一 $q=0.80$ 安全余量，只替换电价通道。
后三行是"全知/完美"口径，不属于可实现的策略，仅用于量化代价。

| 口径 | 总费用 / 元 | 相对全知下界 |
| --- | ---: | ---: |
| 理论完美最低值（全知、全年统一优化） | 12782591.81 | — |
| 完美预测但逐日决策（余量 0） | 12939133.66 | +156541.85（+1.22%） |
| 完美电价、负载/光伏仍因果预测 | 14605084.97 | +1822493.16（+14.26%） |
| 可实现策略 | 14654077.59 | +1871485.78（+14.64%） |

- **与问题2的 735818.83 元差额**：75.2%（553131.08 元）是全知最优本身被抬高——附件4电价
  与负载正相关（0.5077），高负载日恰为高价日，而储能仅占日需求约 17%，即便全知也无法把电
  从高价日搬到低价日；13.2%（97254.01 元）是日末水值近似被放大；11.6%（85433.75 元）是
  紧急购电改按波动电价乘 5 倍结算、惩罚更贵。两问相对下界的比例只差 0.83 个百分点
  （13.81%→14.64%），差别主要在"地板被抬高"而非"策略做得差"。
- **电价通道三步分解**：C1 附件1单曲线 13918258.75 → C2 附件4日内平均形状 +2.72（0.0%）
  → C3 附件4实际电价（完美可预知）+686823.49（93.3%）→ C4 因果预测 +48992.62（6.7%）。
  差异全在日与日之间，且波动本身占 93.3%，不可预知只占 6.7%。把问题2的购电量分布原封不动
  乘附件4实际电价，计划购电费即 +739488.92 元，几乎解释了全部差额。
- **安全余量的两面**：电价完美时余量是纯浪费（多买 1356143 kWh 用不完，白花 1199271.08 元）；
  在真实预测下是划算的保险（不留余量则 465765 kWh 误差全部转为 5 倍紧急购电、304 天、
  298.62 万元），净省 1286336.15 元。未用购电的加权均价 0.5765 元/kWh 低于计划均价
  0.6427 元/kWh，浪费是"便宜时买多了"而非"买贵了"。

详见 `results/最终结果汇总.md` 与 `问题4重算问题2最终论文.md` 第 8 章。

## 运行

```powershell
pip install -r requirements.txt
python final_model_q4_2.py
```

输入自动从 `C题/附件/` 读取（程序会在目录树中自动定位附件目录）：附件1（冷启动先验）、
附件2（负载与光伏实际值）、附件4（波动电价）。运行结果写入 `results/`，论文图写入 `figures/`。

## 主要文件

- `final_model_q4_2.py`：唯一运行入口。
- `deterministic_baseline.py`：预测特征、因果分位数余量、储能 LP 与逐日滚动调度。
- `price_forecast.py`：电价的因果三模型集成预测（近期加权基线＋岭回归＋浅层 LightGBM 动态加权）。
- `seasonal/`：问题2最终版的季节自适应预测组件，**未作任何改动**。
- `export_result4_2.py`：按附件5 模板导出 `results/result4-2.xlsx`。
- `results/最终冻结结果.json`：本文数字的唯一冻结入口。
