# 问题4：波动电价下重算问题3

问题4要求把外网电价由附件1的单条固定日内曲线换成附件4的逐日逐时段波动电价，
重算问题3。本目录**沿用问题3的最终决策方案 $M_9$（储能追索型 LP，$q=0.80$），
只替换电价通道**，其余（负载/光伏因果预测、四时点滚动结构、链式结算规则、
储能物理参数）一律不动，以便把费用差额干净地归因到电价。

## 波动电价口径

- **实际电价** $c_{d,t}$ 取自附件4（365×144），**只用于结算**：计划购电按
  $c_t\min_kx^{(k)}$、下调调整按 $0.5c_t\Delta^-$、上调调整按 $1.5c_t\Delta^+$、
  紧急购电按 $5c_t$。
- **预测电价** $\hat c_{d,t}$ 由第 $d$ 天 $k$ 时刻可用的 $j<d$ 历史实际电价因果
  预测得到（与重算问题2 同一实现），**只进入 LP 目标与储能套利**。
- 两者都由 `gen_price_channel.py` 在 `问题4/重算问题2` 的模块环境下算好后缓存，
  本目录只读取。之所以单独开进程：本目录与 `重算问题2` 各持一份同名但不同分支的
  `deterministic_baseline` / `seasonal`，同进程按名导入会互相覆盖。

电价预测精度（正式评价期）：MAE **0.03994073 元/kWh**，nMAE **5.2725%**，
偏差 +0.00128 元/kWh；实际均价 0.75753、预测均价 0.75881 元/kWh。
与 `重算问题2` 的 README 所载 0.0399 / 5.27% 逐位一致，证明两处用的是同一条电价。

## 代价阶梯（`results/代价阶梯.csv`）

| 口径 | 总费用/元 | 相对全知下界 |
|---|---:|---:|
| 理论完美最低值（全知、全年统一优化） | 12,782,591.81 | — |
| 完美预测但逐日决策（余量0） | 12,943,923.83 | +161,332.02（+1.26%） |
| 完美电价、负载/光伏仍因果预测 | 14,072,142.49 | +1,289,550.68（+10.09%） |
| **可实现策略（本文提交）** | **14,138,543.96** | +1,355,952.15（+10.61%） |

全知条件下问题3 的链式结构是松的（四次承诺取同值即令 $\Delta^\pm=0$），
故理论最优与问题2 是同一个 LP，**两问共享同一块地板**。该下界是紧的，
已构造性验证：把 LP 解原样作为四时点共同承诺下达，真实执行加链式结算得
12,782,591.808513459 元，与 LP 值差 $9.3\times10^{-9}$ 元。

**与问题3（附件1 固定电价）对照**：13,424,276.22 → 14,138,543.96 元，
**+714,267.74 元（+5.32%）**，其中 97.6% 来自计划购电费上升（购电量只涨 0.11%，
均价由 0.62562 涨到 0.65921 元/kWh）。

**与重算问题2（同一波动电价）对照**：14,654,077.59 元，即 $M_9$ 的四时点滚动
结构比问题2 的单时点日前结构**便宜 515,533.63 元（3.52%）**。

## 物理可行性与一致性（独立复核，非主程序自检）

| 检查项 | 结果 |
|---|---|
| 能量平衡最大误差 | $4.547\times10^{-13}$ kWh，违规 0 |
| SOC 递推最大误差 | $5.457\times10^{-12}$；SOC 越界 0 |
| 充放电越限 | 0 / 0 |
| 光伏恒等式 $g+w=P^{act}$ 最大误差 | $2.274\times10^{-13}$；负流量 0 |
| $x-y-r$ 最大误差 | $4.583\times10^{-13}$ |
| 费用恒等式 $C_{plan}+C_{adj}=C_{grid}$ / $C_{grid}+C_{emer}=C_{total}$ | $5.8\times10^{-11}$ / $1.5\times10^{-11}$ |
| `result4-3.xlsx` 全天购电量合计 vs 汇总 | 20,349,127.8414 vs 20,349,127.8412 ✓ |
| `result4-3.xlsx` 全天购电费合计 vs CSV $C_{plan}$ | 13,414,444.41 vs 13,414,444.37（Excel 15 位有效数字，差 0.04 元）|

xlsx 的“全天购电费”列填的是**计划购电费**（$\sum_t c_t\min_kx^{(k)}$），
不含调整费，故它不等于 $C_{grid}$；$C_{grid}=C_{plan}+C_{adjust}$
= 13,414,444.37 + 592,850.74 = 14,007,295.11 元，已对平。

## 复现

```bash
python gen_price_channel.py     # 先跑一次，生成 cache/price_channel.npz
python export_result3.py        # 跑 M9 全年并导出 results/ 与 figures/
python oracle_lower_bound3.py   # 全知下界 LP 与可达性验证
python cost_ladder.py           # 代价阶梯（依赖上一步的 理论最优.json）
python run_models.py            # 九个决策模型的横向对照（可选）
python accuracy.py              # 预测精度诊断（可选）
```
