# C题符号规定（兼容入口）

> **唯一权威版本：** `../C题符号规定.md`  
> **时间口径依据：** `../../时间点与时间段统一处理说明.md`

本文件不再维护第二套独立符号定义，以防两个副本再次产生时间下标漂移。AI或人工处理 `zzb` 目录下的程序和论文前，必须完整读取上一级 `C题符号规定.md`，并以其内容替代本文件的历史版本。

## 强制摘要

1. 自然日物理时间轴使用 $i=1,\ldots,144$：
   - $I_{d,1}$ 为00:00—00:10，对应输入点 `00:10`；
   - $I_{d,37}$ 为06:00—06:10；
   - $I_{d,144}$ 为23:50—次日00:00，对应 `0:00+1`。
2. 附件5计划行时间轴使用 $j=1,\ldots,144$：
   - $J_{d,1}$ 为00:10—00:20；
   - $J_{d,36}$ 为06:00—06:10；
   - $J_{d,144}$ 为次日00:00—00:10。
3. 唯一映射为

   $$
   J_{d,j}=I_{d,j+1}\quad(j=1,\ldots,143),
   \qquad
   J_{d,144}=I_{d+1,1}.
   $$

4. 06:00、12:00、18:00分别从计划段 $j=36,72,108$ 开始调整。
5. 自然日执行序列为 $J_{d-1,144}+J_{d,1:143}$，SOC日循环约束在执行完 $J_{d,143}$ 后。
6. 计划和调整量使用 $j$；实际负载、实际光伏、实际电价、执行充放电和SOC使用 $i$。
7. 输入实际数据不能直接按相同列号与计划数组配对，必须使用权威符号表中的 $\pi$、$\psi$ 映射。
8. Python中必须区分：

   ```python
   PHYSICAL_STAGE_START = {0: 0, 6: 36, 12: 72, 18: 108}
   PLAN_STAGE_START = {0: 0, 6: 35, 12: 71, 18: 107}
   ```

9. 2025年1月1日00:00—00:10冷启动购电为0；问题2—4从1月连续预运行，2月1日不重置SOC。
10. 附件3是未来整点点预测，十分钟光伏预测采用线性插值；00:00计划第144段光伏预测固定为0。

## 禁止事项

- 禁止重新定义单一 $t$ 同时代表物理段和计划段；
- 禁止把输入点 `00:10` 解释为00:10—00:20；
- 禁止把计划段 $j=36$ 和物理数组零基下标36当成同一种编号；
- 禁止把 $J_{d,144}$ 纳入第 $d$ 日储能统计或SOC日循环；
- 禁止在决策时读取尚未发生时段的真实数据；
- 禁止在本兼容入口中另建一套与权威文件平行的符号表。
