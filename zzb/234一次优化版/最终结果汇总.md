## 四、统计显著性：四个问题的费用差都未被检出

7 日区块 Bootstrap，2,000 次重采样、seed = 20260911，对**未做年末校正的原始费用差额**检验：

| 问题 | 全年差额/万元 | 95% CI/万元 | 含 0？ | $P(\text{差额}\ge0)$ | 更省月数/总月数 |
|---|---:|---|---:|---:|---:|
| 问题2 | −8.39 | [−22.21, +3.97] | **是** | 0.089 | 6/11 |
| 问题3 | +1.05 | [−1.17, +3.62] | **是** | 0.815 | 5/11 |
| 问题4-2 | −9.36 | [−24.05, +4.47] | **是** | 0.078 | 7/11 |
| 问题4-3 | +0.30 | [−2.19, +3.18] | **是** | 0.592 | 5/11 |

**四个问题的费用差在区块 Bootstrap 下都覆盖 0**。把区块长度换成 3 / 14 / 28 日后，16 个组合的区间仍全部覆盖 0。因此只能说"在该区块设定下费用差未被检出"，**不构成显著性结论**，也不应反过来说"两模型等价"。

**但另一类差异是被检出的**：

| 对照 | 点估计/万元 | 95% CI/万元 | 含 0？ |
|---|---:|---|---:|
| 问题3 `exact-greedy` − `fixed-greedy` | −2.71 | [−3.93, −1.73] | **否** |

即"**换掉目标函数带来的改善**"在统计上被检出，而"相对上游的费用差"未被检出——**两者不是同一件事，不应混用**。

## 八、复现

在 `opt/` 目录下（Python 3.10）：

```bash
python run_single.py --problem Q2 --mode reserve-mpc      # 问题2 最终档位
python run_stage.py  --problem Q3 --mode exact-greedy     # 问题3 最终档位
python run_single.py --problem Q4-2 --mode reserve-mpc    # 问题4-2 最终档位
python run_stage.py  --problem Q4-3 --mode exact-greedy   # 问题4-3 最终档位
python export_final.py --problem Q2                       # 导出结果 CSV
```

`export_final.py` 不改动 `run_single.py` / `run_stage.py`：它在 `opt_core.run_day_single` 上挂记录钩子捕获每次执行的 (承诺, 执行结果)，复用两脚本各自的 `simulate` 跑一次最终档位后按上游格式导出。脚本内置一致性断言，重跑总费用与 `opt/结果冻结.json` 的原始值不符即报错。

## 九、必须一并说明的限制

1. **四个问题的费用差在统计上都未被检出**（§四），不应表述为"显著更省"或"显著更贵"。
2. **优化是权衡而非全面改进**：紧急购电量与紧急天数全部上升，若每次紧急采购有固定成本，经济优势可能被抵消（§五）。
3. **问题3 / 问题4-3 的修正首先是为了模型正确**：`legacy`（上游口径）的校正后费用反而更低，但它的阶段目标把上调量少算 $1.0c$，与题面链式结算不一致，"更省"来自口径错误。选 `exact-greedy` 的首要理由是目标函数与题面严格一致。
4. **四个决策时刻的储备覆盖率不齐平**（0.7515 / 0.7754 / 0.8174 / 0.7934），单一分位数无法同时校准四个长度不同的窗口；该偏差在四个档位间共同，不影响档位比较，但未修正。
5. **全部结论只覆盖一个自然年度**，无法验证跨年度季节泛化。
6. **未做 Diebold—Mariano 检验**；问题4 电价信息集敏感性、48–72 小时多日滚动、价格—净负荷联合残差场景均未建模。
