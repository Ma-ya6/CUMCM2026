# exact 分支的独立验证

> `chain_misprice_yuan = 0` 在 exact 档是按定义置零，**不构成正确性证据**。
> 本文件用三条与实现无关的独立检验替代它。

## 检验 1：闭式增量对照（$m=80,\ r=100,\ c=1$）

| $x$ | 期望 $\Delta F$ | 实测 $\Delta F$ | 判定 |
|---:|---:|---:|---|
| 70 | 5.0 | 5.0 | ✓ |
| 90 | 5.0 | 5.0 | ✓ |
| 110 | 15.0 | 15.0 | ✓ |

**判定：通过**

## 检验 2：望远镜恒等式

对任意承诺路径 $x_0,\dots,x_K$，题面链式结算可分解为

$$c\,x_0+\sum_{k=1}^{K}\Delta F_k=c\min_k x_k+0.5c\sum_k \Delta^-_k+1.5c\sum_k\Delta^+_k=F_{\mathrm{settle}}(x_0,\dots,x_K).$$

随机路径数：500（段数 2–6，价格 $c\in[0.2,1.5]$ 元/kWh）

最大偏差 $|c x_0+\sum_k\Delta F_k-F_{\mathrm{settle}}|$ = **1.137e-13** 元

**判定：通过**（阈值 $10^-8$）

## 检验 3：单时段网格穷举对照 MILP

随机场景数：60（单时段、末态储电固定，初始储电 $\in[E_{\min}+200,E_{\max}-200]$，网格步长 0.02 kWh）

$|\Delta F(x^*) - \min_x\Delta F(x)|$ 的最大值 = **6.905e-03** 元，超出步长容差的场景 0 个

**判定：通过**（容差 = 网格步长 $\times\Delta F$ 最大斜率 $1.5c$；网格为离网格点，故不能要求逐位相等）

## 结论

三条检验全部通过。
`exact` 分支的目标函数与题面链式结算等价性由此独立成立，不再依赖「误价为 0」这一按定义置零的量。
