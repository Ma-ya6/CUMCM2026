# 问题2—4 最终模型包

本目录的最终交付按问题分为三个文件夹：

- `问题2最终模型/`：最终策略 `reserve-mpc`；
- `问题3最终模型/`：最终策略 `exact-greedy`；
- `问题4最终模型/`：问题4-2 使用 `reserve-mpc`，问题4-3 使用 `exact-greedy`。

`opt/` 保存重算脚本、消融实验与检验证据，`verify/` 是对原上游冻结结果的只读核对包，
不作为修正预测层后的最终数字来源。最终数值以 `opt/结果冻结.json` 和三个“最终模型”
文件夹为准；`opt/finalize.py` 负责核验并同步副本，`最终文件清单.json` 保存 SHA-256。

## 统一口径

费用比较统一采用年末储能残值校正

$$C^{\mathrm{adj}}=C-0.7662(E_{\mathrm{final}}-6000).$$

风险分位数 $q=0.80$ 由题面紧急购电相对常规购电的代价比理论推导，其他 $q$ 仅作
敏感性分析，不据评价期结果重新选参。
