# 模型3 决策优化版：七种决策策略的费用对照

**同一条预测链，七种决策模型，一套物理与经济规则。** 各模型之间的费用差**只来自决策策略本身**。

## 目录结构

```
common.py          预测层的公共常量与数据装载（与 模型3 逐位相同）
forecasts.py       负载因果集成 + 光伏按"发布时刻×日内小时"融合（同上）
accuracy.py        预测准确度核算（同上）
cache/             预测所需的缓存（同上）
dispatch_core.py   公共底座：物理执行、链式/两元结算、全年滚动仿真
models.py          七个决策模型（唯一的差异所在）
run_models.py      驱动脚本，产出 results/
results/           决策模型对比.csv / 决策模型逐日结果.csv / 决策模型元数据.json
```

## 七个决策模型

| 代号 | 模型 | 建模范式 | 不确定性处理 |
|---|---|---|---|
| M1 | 确定性经济调度 LP | 确定性优化 | 预报即真值，不加任何余量 |
| M2 | 分位安全余量 LP | 确定性优化 | 约束侧加 q=0.80 历史分位余量（**模型3 原口径**） |
| M3 | 两阶段随机规划 | 随机优化 | 9 个历史残差分位情景等权，紧急购电为追索 |
| M4 | 均值–CVaR 随机规划 | 随机优化 | 0.5·期望 + 0.5·CVaR(0.90)，λ=0.5 |
| M5 | 盒式鲁棒优化 | 鲁棒优化 | 逐时段历史最大残差构成的盒式不确定集 |
| M6 | 精确链式 MILP | 混合整数优化 | 与 M2 同用 q=0.80 余量，但结算项用 0-1 变量精确刻画 |
| M7 | 规则型启发式 | 无优化 | 净负荷跟随 + 储能按电价四分位充放 |

所有模型共用同一接口 `plan(ctx) -> 购电向量`，决策时刻为 0:00/6:00/12:00/18:00，
每次只能调整尚未执行的时段。

## 读法：四条可报告的结论

1. **M6 与 M2 逐位相同**（13,748,164.50，开发期/留出期也一致到分）。
   精确链式 MILP 与 模型3 的锚定凸化给出**同一个解**，说明本实例中承诺序列全程单调非降，
   凸化不是近似而是**精确**的。这是对 模型3 的一处独立佐证。

2. **M1 最便宜，但省的是"赌预报"的钱。** 去掉安全余量后紧急购电从 15,832.90 kWh
   暴涨到 116,812.66 kWh（7.4 倍），紧急购电费 643,213.77 元。M1 只是把风险从
   常规购电挪进了尾部事件，并不代表它更稳。

3. **随机规划在本实例上反而更贵。** M3/M4 把紧急购电压到 7,000 kWh 量级，
   代价是系统性超购——M4 未用计划电量 2,342,166.87 kWh，为七者最高。
   分位情景等权期望低估了尾部，模型就靠多买来"买保险"。

4. **M5 盒式鲁棒灾难性保守**（+73.92%）：计划购电量 3,542 万 kWh（M2 的 1.6 倍），
   未用计划电量 1,424.6 万 kWh，紧急购电为 0。逐时段取历史最大残差、不给不确定集
   任何预算约束，这一定是最坏情形下的做法，不适合本题。

**M7 是唯一出现违约费的模型**（2,057,444 元，链式减两元差额同为 2,030,855 元）：
规则会在电价低时压计划、电价高时抬计划，两侧都动，同时触发 0.5c 与 1.5c。

## 运行

```bash
python run_models.py
```

脚本内置锚点自检：M2 必须复现 模型3 的冻结值 `13,748,164.499748`。当前实测
13,748,164.499748461，与冻结值差 1.9e-9（浮点累加），分项逐位一致。
自检失败则该次结果不可跨模型比较。

（注：M2 的实现必须逐字照抄 模型3 `solve_stage` 的目标矩阵——那里的 `eb`/`eo`
两个变量块命名与注释相反，`1.0c` 实际加在 `(ref−x)⁺` 上。改动这一处会得到
镜像的错误结果 13,668,146.63。）

## 无信息泄露说明

预测层与风险分位数全部因果：`causal_residual_quantiles` 对第 d 天只使用 j<d 的
残差样本，`residual_hist` 传入的也只是当日之前的历史，决策模型看不到当日真值。
`q=0.80` 是事前固定的风险偏好，不是按正式期费用挑出来的。
