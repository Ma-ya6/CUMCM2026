# 问题2最终优化版

本目录只包含最终模型、最终论文和最终结果。

## 最终模型

季节水平预测（光伏窗口＋在线水平校正，关闭周效应）＋因果分位数安全余量（开发期选择 $q=0.75$）＋确定性储能线性规划。

## 运行

```powershell
pip install -r requirements.txt
python final_model_q2.py
```

输入文件自动从 `C题/附件/附件1.xlsx` 和 `C题/附件/附件2.xlsx` 读取。运行结果写入 `results/`，论文图写入 `figures/`。

## 主要文件

- `问题2最终论文.md`：完整问题2论文。
- `模型分析.md`：最终选型、风险与结果解释。
- `final_model_q2.py`：唯一运行入口。
- `results/全年逐10分钟策略.csv`：全年完整策略。
- `results/全年逐日结果.csv`：全年汇总。
- `results/四天表1购电结果.csv`、`四天表2储能结果.csv`、`四天紧急购电结果.csv`：指定日期结果。
- `results/最终冻结结果.json`：论文数字的唯一冻结入口。

正式评价期为2025-02-01至2025-12-31，共334天；一月用于预测预热和储能状态连续递推，但不计入正式费用。

程序和论文采用C题统一符号：`c/L/P/x/y/r/g/w/u/v/e/E/m`。全年CSV字段也按这些符号加英文含义命名；其中带 `_kw` 的列为功率，带 `_kwh` 的列为十分钟或日累计电量。
