# 问题2 综合版本（0911）

C 题问题 2 的**最终提交版**：以 `问题2/最终优化版` 为基础，统一采用《C 题符号规定》的符号体系，并把三代对比模型（模型1、模型2、模型2再优化）与优化过程记录一并纳入。

## 最终方案

**季节水平预测（光伏有效窗口 + 水平校正，关闭周效应）+ 因果分位数安全余量（$q=0.80$）+ 确定性储能线性规划**

$q=0.80$ 直接取 5 倍紧急电价下的报童临界比 $4c/(4c+c)$，是事前给定的理论值，不由任何评价期回测挑选；`results/风险参数敏感性.csv` 中的 $q$ 网格只作事后对照。

- 正式评价期：2025-02-01 至 2025-12-31，共 334 天（48,096 个时段）
- 全年总费用：**13,918,258.75 元**（比 M1 低 64,430.93 元；比 M2 优化版高 3,131.22 元，两者基本持平）
- 计划购电 22,011,526.88 kWh / 13,418,699.15 元；紧急购电 80,111.20 kWh / 499,559.60 元
- 净负荷 MAE 247.43 kW（nMAE 8.25%，偏差 −0.99 kW）
- 全部物理约束违规数为 0，最大能量平衡误差 $2.27\times10^{-13}$ kWh

## 口径说明

- 储能初值按《C 题符号规定》§9.5 的跨日连续口径取 $E_{1,0}=6000$ kWh（2025.1.1 0:00）逐日递推，2 月 1 日初值由 1 月 31 日末储电量继承（$E_{32,0}=E_{31,144}$），不重新初始化；本模型递推值为 $E_{32,0}=10800$ kWh。
- 净负荷允许为负，**评价时不做非负裁剪**（裁剪会使 MAE 由 247.84 虚增至 535.55 kW）。
- 一月的预测与储能递推参与预热，但不计入正式费用。

## 已知遗留（不影响最终结果）

1. `seasonal/` 中的 `scenario_generator.py`、`stochastic_lp.py` 为 SAA-CVaR 路线遗留，最终入口 `final_model_q2.py` **不使用**；保留以便复核 §8 的对比结论。
2. `seasonal/adaptive_forecast.py` 的注释引用了 `tests/test_no_leakage.py`，该测试目录未随最终优化版提供。最终模型的因果性由代码路径与固定随机种子（`n_jobs=1`、`deterministic=True`）保证。
3. 场景名义 90% 区间实际覆盖率仅 80.94%（M3 口径），已在论文 §5.3 如实披露；最终方案不使用场景，故不作为结论依据。
