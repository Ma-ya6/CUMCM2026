# 采用模型1决策方式并适当优化能否减少花费？——计算与比较

## 1 两种决策方式的差别

模型1与模型2**共用同一套因果预测骨干**（`recent_weighted` / `weekly_load_baseline` /
`day_features` / LightGBM 时间验证早停 / `adaptive_error_weights`），差别只在**决策规则**：

| | 规则 A（模型1） | 规则 B（模型2 / 本文 M3） |
| --- | --- | --- |
| 不确定性刻画 | 无场景。净负荷预测误差的**因果分位数** $m_{d,t}=Q_q(\varepsilon)_{d,t}$ | $S=20$ 个等概场景 |
| 优化问题 | **确定性单场景 LP**：$\min\sum_t p_t q_t$ | **两阶段 SAA-CVaR** |
| 风险控制 | 安全余量 $\text{net}\leftarrow\text{net}^{fc}+m_{d,t}$ | CVaR 权重 $\beta$ |
| 储值处理 | 日末水值 $\lambda=\eta_d\bar p$ | 场景一致 + 无强制日末 |
| 决策变量维度 | $5\times144$ | $5\times144\times S$ |

规则 A 的 LP 约束为 $q_t-c_t+d_t-w_t=(\text{load}^{fc}_t+m_t)-\text{pv}^{fc}_t$，
即"按加过安全余量的净负荷预测买电"，再由 LP 自行安排充放电套利。

**关键**：正因两者共用预测骨干，可以构造 **2×2 交叉对照**，把"预测变好"与
"决策变好"的贡献分开。

## 2 适当优化的方向：分位数 $q$ 的选择

规则 A 唯一的风险旋钮是分位数 $q$。

- **无储能时**的最优解是新闻vendor解：多买 1 kW·h 花 $p$，少买则要付 $5p$，
  故买到边际 $P(\text{需要})>1/5$ 为止，即 $q^*=1-c_o/c_u=0.80$。
- **但本问题有储能作为追索手段**：多买的电可存起来在后续高价值时段使用，
  不必当期作废，因此真实最优 $q$ 应**低于** 0.80。

实测证实了这一点（下表）。因此"适当优化"= 在**开发期**（2025-02-01—08-31）
选出 $q^*$，再在留出期与全年报告。选参不使用任何留出期信息。

## 3 计算结果

### 3.1 分位数敏感性（全年正式期，334 天）

| $q$ | 规则A + 基础集成 | 规则A + 季节周预测 |
| --- | --- | --- |
| 0.60 | 14,309,471 | 14,267,053 |
| 0.65 | 14,089,424 | 14,031,120 |
| 0.70 | 13,969,217 | 13,913,228 |
| **0.75** | **13,931,291** | **13,880,040** |
| 0.80 | 13,982,690 | 13,933,251 |
| 0.85 | 14,128,844 | 14,074,866 |

- $q$ 的极差为 **2.8%**（14.31M ↔ 13.88M），**远大于**预测改进带来的 0.37%；
- 开发期选出的 $q^*=\mathbf{0.75}$（两套预测一致），留出期最优为 0.75（F1）与
  0.70（F2），**选参在留出期稳定**；
- 在**每一个** $q$ 上，季节周预测都优于基础集成——说明预测改进与决策改进**可叠加**。

## 4 结论

### 4.1 能减少，但**不是"显著"减少**

以模型1原配置为基准：

| 对照 | 降幅 |
| --- | --- |
| → 模型1决策 + 分位数优化 | −51,399 元（**−0.37%**） |
| → 再叠加季节/周效应预测 | **−102,650 元（−0.73%）** |
| → 相对模型2优化版 | −35,088 元（−0.25%） |
| → 相对模型2再优化 M3 | **−192,061 元（−1.36%）** |

**量级判断**：在约 1400 万元的总花费上，最优组合仅比模型1原配置省约 **10 万元（0.73%）**，
比模型2优化版省约 **3.5 万元（0.25%）**。这一量级**不足以称为"显著"**。

### 4.2 真正的杠杆是分位数，不是预测精度

- 分位数 $q$ 从 0.60 调到 0.75 可省 **2.8%**；
- 预测从基础集成换成季节周校正只省 **0.37%**；
- 决策规则从确定性 LP 换成两阶段 CVaR（M3 相对最优规则A）反而**多花 1.36%**。

原因是本问题的费用结构几乎完全由"多买 vs 少买"的**边际替代率**决定：
多买 1 kW·h 的成本是 $p$，少买 1 kW·h 的成本是 $5p\cdot P(\text{不足})$。
谁把这个比例调得准，谁就便宜；预测精度只改变最优购买量的落点，不改变替代率本身。

### 4.3 确定性 LP 在**期望成本**上优于随机规划，但代价是尾部暴露

| | 规则A $q^*{=}0.75$ + 季节周预测 | 规则B（M3） |
| --- | --- | --- |
| 总成本 | **13,880,040** | 14,072,101 |
| 日费用 CVaR95 | 73,341 | 73,111 |
| 日费用标准差 | 15,829 | — |
| 紧急购电**天数** | **151** | 67 |
| 紧急购电**总量** | 111,832 kW·h | 67,964 kW·h |

两者**尾部严重度几乎相同**（CVaR95 差 0.3%），但规则 A 把风险摊薄成
**更多次、每次更小**的紧急购电（151 天 vs 67 天）。因此：

- 若考核指标是**全年总花费**，规则 A + 季节周预测胜出；
- 若考核指标包含**紧急购电发生的频次**或**运营扰动**（151 天需要启动紧急采购，
  是实实在在的运维负担），规则 B 更稳。

**这是一个多目标问题，不存在单一最优解。**

### 4.4 建议

1. **采纳规则 A 的结构**（确定性 LP + 分位数安全余量），因为它在同样尾部风险下
   期望成本最低，且求解规模从 $5\times144\times20$ 降到 $5\times144$，**单日求解
   快一个量级**，实现与维护成本都低得多。
2. **分位数 $q$ 用开发期标定为 0.75**，而非教科书新闻vendor解的 0.80——
   差值来自储能的追索价值。
3. **保留季节/周效应预测**：它在每一个 $q$ 上都带来稳定的 0.37% 改进，且是**免费**的
   （不增加决策维度）。
4. 若运维方在意紧急采购频次，可把目标改为
   $\min\ \text{总成本}+\rho\cdot(\text{紧急购电天数})$，用 $\rho$ 在两类解之间插值。
