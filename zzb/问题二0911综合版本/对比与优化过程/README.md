## 符号口径提醒

这两份对比文档写作时尚未全面对齐《C 题符号规定》，其中：

- 用 $p_t$ 表示电价、$q_t$ 表示计划购电量——按符号规定应分别为 $c_t$、$x_{d,t}$；
- 用 $x_t$ 表示计划购电——多日问题应带日期下标 $x_{d,t}$；
- 用 $P_{\max}$ 表示最大充放电功率——按符号规定为 $P_{\mathrm{st}}^{\max}$。

`问题2综合版论文.md` 中引用这些结论时已全部换算为符号规定口径。存档文件保留原文，以便核对数值来源。
