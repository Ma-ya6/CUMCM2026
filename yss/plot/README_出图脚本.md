## 三、典型周是怎么来的

Q2-1 和 Q3-1 里的"典型周"不是挑某七天，而是**按星期几对全年求平均**：

1. 读 `表A_逐10分钟.csv`，按 `date` 取出星期几（0 = 周一）；
2. 同一星期几的所有日期，对 144 个时段逐一取算术平均；
3. 得 7×144 = 1008 行的平均表，行是周一…周日，列与表 A 同名列一致。

天数：周一/二/三/六/日各 48 天，周四/五各 47 天（334 天除不尽），图标题里标了实际天数。
平均表另存为 `Q2_典型周_星期平均.csv`、`Q3_典型周_星期平均.csv`，可以直接对着出别的图。
函数是脚本里的 `typical_week()`，就在 Q2-1 绘图函数上面。

**顺带看出一个周内规律**：这份数据的"周末"是**周五和周六**——0:00 那一格负载，周一到周四和周日都在 3700–3770 kW，周五 2673、周六 2755，低约 27%。

> 早先用导出脚本的默认样例周（2025-03-17—03-23）画过一版，已移入 `figures/data_figure/_旧样例周/`。
> 那个日期是 `export_plot_data.py` 里 `--week` 的硬编码默认值，没有任何代表性依据，故弃用。

## 四、画图的几条固定口径

1. **单位**：表里 `*_kw` 是功率，`*_kwh` 是十分钟电量。画在同一根轴上时电量乘 6 变成功率（脚本里的 `TO_KW = 6.0`）。SOC 是 kWh，走右轴。
2. **时段**：默认 334 天正式期（2/1–12/31），13 张图都用这个口径；另有 365 天数据在 `表格/自然年365天/`，**两套不可混用**。
3. **费用口径**：本版 `correction_applied_yuan = 0`，年终 SOC 恰好回到 6000，所以**没有年末残值校正**，图上的费用就是实际费用，不要再去乘 λ。
4. **坐标轴颜色**：左右轴刻度与标签一律 `#333333`，颜色只用来区分曲线。
5. **图内不写图题**，标题由文件名承担，正文图题在 Word/LaTeX 里加。
6. **色板**：`数模/plot_style.py`。跨问题四张图里，Q2 = 深蓝、Q3 = 青绿、Q4-2 = 亮蓝、Q4-3 = 紫，四张图之间保持一致。

## 五、图上出现的几个数（写论文时可引用）

| 指标 | Q2 | Q3 | Q4-2 | Q4-3 |
|---|---:|---:|---:|---:|
| 正式期总费用 / 万元 | 1386.46 | 1343.90 | 1459.52 | 1415.81 |

- **覆盖率按模型族分裂**：reserve-mpc 两问都是 80.84%，贴着 0.80 的名义目标；exact-greedy 两问都是 75.15%，系统性欠覆盖约 5 个百分点。这与"exact-greedy 的最优 q 更低（0.65）"互相印证。
- **费用差距分解**：C0 相同（Q2/Q3 为 1222.83 万元，Q4 两问为 1278.14 万元），差距主要来自净负荷与光伏预测。
- **Q2 与 Q4-2 的最省点恰好是基线 q=0.80**；Q3 与 Q4-3 的最省点在 0.65，比基线分别便宜 5.59 万元和 4.07 万元。

## 六、注意事项

- **X-2 的口径**：表 F 里 C0 的起始 SOC 放松到了 10800，所以 `C1−C0` 这一段混着"初始资源放松"的影响，图例写成"决策结构（含初始资源放松）"，不宜直接叫作决策结构损失。出处 `audits/DF补算汇总.md` 有同样提醒。
- **覆盖率别过度解读**：仓库 `README.md` 的"未闭合事项"里写明 R 覆盖率与 F 差距不能过度解释，图注措辞要保守。
- **D 的最优点不替换基线**：q 扫描只做事后敏感性，基线固定 q=0.80，脚本不会自动改用扫描出的最省点。
- 写 csv 时若文件正被 Excel 占用，脚本会打印提示并跳过写表，继续画图；关掉 Excel 重跑即可。
