# 问题一 · 两种日循环口径的对比与选用建议

---

## 一、分歧从哪里来

题面原文只说"储能设备在 0:00 和 24:00 的储电量相同"，**没有规定这个共同值是多少**。
而附录 1 写了一句"假设 2025 年 1 月 1 日 0:00 的电量为 6000 kWh"。

于是产生两种自洽的读法：

| | 约束 A（固定） | 约束 B（自由） |
|---|---|---|
| 日循环约束 | $E_0=E_{144}=6000$ | $E_0=E_{144}$，共同值自由 |
| 依据 | 附录 1 给出的初始储电量 | 题面只要求两端相等 |
| 物理含义 | 计划从真实初始状态出发、当天回到同一状态，可直接执行 | 把这一天看作纯循环调度周期，考察储能容量潜力 |
| 隐含代价 | 无 | 计划假定起点有 8550 kWh，实际只有 6000，执行前需补足 |

---

## 二、数值对比

| 项目 | 约束 A（固定） | 约束 B（自由） | 差异 |
|---|---:|---:|---:|
| 优化得到的循环储电量 | 6000 kWh | 8550 kWh | +2550 kWh |
| 全天购电量 | 59482.6990 kWh | 59482.6990 kWh | 0 |
| 全天购电费 | 35126.9486 元 | 35118.5986 元 | **−8.35 元（−0.024%）** |
| 平均购电价 | 0.5905 元/kWh | 0.5904 元/kWh | −0.0001 |
| 充电总量 | 20740.6661 kWh | 20740.6661 kWh | 0 |
| 放电总量 | 16799.9396 kWh | 16799.9396 kWh | 0 |
| 往返损耗 | 3940.7266 kWh | 3940.7266 kWh | 0 |
| 弃光电量 | 0 | 0 | 0 |
| 无储能基准购电费 | 48052.0466 元 | 48052.0466 元 | 0 |
| 储能节省 | 12925.0980 元（26.8981%） | 12933.4480 元（26.9155%） | +8.35 元 |
| 求解耗时 | 0.038 秒 | 0.009 秒 | — |

两个模型的**购电量、充放电总量、往返损耗、弃光量完全相同**，
差别只在于这些电在时间上的分布，以及由此带来的 8.35 元费用差异。

分时段看，差异集中在两处：

| 时间段 | 约束 A（固定） 充电量 | 约束 B（自由） 充电量 |
|---|---:|---:|
| 0:00–4:00 | 4500.0000 | 1666.6667 |
| 20:00–24:00 | 5333.3333 | 8166.6667 |

约束 B（自由） 的循环工作点更高，凌晨可用于充电的余量变小，
于是把充电挪到电价同样低廉的深夜时段。六个指定时段的购电量两版完全一致。

---

## 三、可行性关系

约束 A（固定） 要求 $E_0=E_{144}=6000$，约束 B（自由） 只要求 $E_0=E_{144}$。
把任意一组满足 A 的可行解代入 B，取 $E_0=E_{144}=6000$ 即可满足 B 的全部约束，
因此 **A 的可行域是 B 的子集，B 的最优费用必然不高于 A**。

实测差距 8.35 元、万分之二点四，说明这个松弛几乎没有价值——
把循环工作点从 6000 抬到 8550 并不带来实质性的套利增益。

---

## 四、选用建议

**以约束 A（固定） 为主结果**，理由是它直接对应附录 1 给出的物理初始状态，
生成的是可以直接执行的调度计划；约束 B（自由） 的计划假定了 8550 kWh 的起点，
超出实际初始电量 2550 kWh，执行时需要先补足这一差额。

**把约束 B（自由） 作为灵敏度分析**，在论文里写一句即可：

> 题面对 0:00 与 24:00 的储电量只要求相等，并未规定共同取值。
> 若将该共同值交给优化决定，最优循环储电量为 8550 kWh，
> 全天购电费由 35126.95 元降至 35118.60 元，变化幅度仅 0.024%，
> 表明结论对该口径不敏感。

这样处理的好处是：主结果有明确的物理依据，同时向评委展示了
你已经识别出口径上的歧义，并做了量化检验。

**不建议的做法**是两种口径混用——比如正文按 6000 写、结果文件却按 8550 生成。
一旦有评委核对，会认为前后不一致。选定一种并全程统一即可。
