# 支撑材料使用与复现说明

## 交付范围

本目录包含独立运行所需的原始附件和源码；解压后先还原压缩明细，并按下述步骤配置环境。保留原项目相对目录；正式提交结果位于 `结果/result/`，包含 result1.xlsx、result2.xlsx、result3.xlsx、result4-2.xlsx、result4-3.xlsx。

已收录 `C题/C题.pdf`、`C题/附件/` 下的原始附件1—4和附件5模板、问题1—4求解/预测/导出源码、验证源码及小型核验证据、主模型逐日和逐十分钟结果、计划数组、冻结汇总、预测缓存、论文相关方法说明、表D/F/G/H等小型数据表，以及全部出图和数据导出代码。

包内收录 `图表/综合/补跑输出/` 下38个D/F实验摘要和4个C0核验JSON，合计29615字节，供统一 export/verify 入口读取实验证据。

未收录重复的图表逐十分钟表、图片成品、deps/results 与 deps/cache、消融的完整中间轨迹、虚拟环境及字节码。图表逐十分钟数据由主模型结果和缓存导出；图片由绘图代码生成。源码保持原样，不拼接或删减模型实现。论文正文引用文献的下载PDF因提交包体积限制未收录，文献著录见论文的参考文献表。

`代码/` 是完整运行源码的唯一目录。

## 环境

在解压得到的“支撑材料”根目录打开终端，使用 Python 3.10（64位），执行：

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

下面命令中的 `python` 应指向该虚拟环境；Windows 可先执行 `.venv\Scripts\activate`。依赖按 requirements.txt 固定版本安装，优化求解器采用 SciPy 自带 HiGHS。Linux/macOS 使用 `.venv/bin/python`。不要调整目录层级，也不要删改原始附件。

## 解压后的第一步：还原无损压缩明细

为压缩体积，4份主模型逐十分钟CSV采用 `.csv.xz` 无损存储。安装Python后，在本目录执行 `python 还原压缩明细.py`，或双击 `先运行_还原明细.cmd`。脚本只解压并逐文件核对原始SHA-256，不运行预测、求解或复现计算。还原后各主模型数据路径与原项目完全一致；原有5个提交工作簿未经此转换，可直接打开。

## A. 利用已交付结果恢复表格与图（无需全年优化）

先完成上述明细还原。预测缓存 `代码/共享/cache/rebuilt.npz` 已附上，因此以下导出不需要重跑预测或全年优化：

```bat
python 代码/共享/导出result.py
python 代码/共享/project.py export
```

第一条按附件5重新导出五个提交工作簿；第二条恢复图表数据表、全年汇总、表G、结果图和综合图。表D/F/H已附小型成品，export 不重新计算这些实验。部分核验 JSON 会随 export 更新为当前交付目录的文件清单。

问题1求解图单独生成：

```bat
python 代码/问题1/plot_q1.py "结果/问题1/约束A（固定）_完整结果.csv" "图表/问题1/求解图/约束A（固定）"
python 代码/问题1/plot_q1.py "结果/问题1/约束B（自由）_完整结果.csv" "图表/问题1/求解图/约束B（自由）"
```

问题1检验图及其证据由下述 C 中的问题1脚本生成。原项目图表的作用与生成入口见 `图表/图表说明.md`；图形文件输出为代码所设置的格式。

## B. 从原始附件重新计算主模型（本次未执行）

如需确认从原始输入重建，请先复制一份本交付包作为工作目录。在该副本删除 `代码/共享/cache/` 后按顺序执行：

```bat
python 代码/问题1/solve_q1_ab.py
python 代码/共享/project.py run
python 代码/共享/导出result.py
python 代码/共享/project.py export
```

全年入口顺序计算 Q2、Q3、Q4-2、Q4-3；问题1须先运行，提交 result1 依赖它的结果。预测缓存删除后由输入附件和因果预测源码重建。全年重算会覆盖副本中的对应结果，不能把这一步理解为单纯出图。

只重算一个问题可用 `python 代码/共享/project.py run --problem Q3`，也可选择 Q2、Q4-2、Q4-3 或 Q4（两种问题4）。费用以正式期2025-02-01起334天为主，同时保留自然年365天数据，勿混用两种统计口径。

## C. 检验现有结果

先完成 A 中的 export，以更新当前目录的图表数据与校验清单，再执行：

```bat
python 代码/共享/project.py verify
python 代码/共享/project.py verify --deep
python 验证/代码/问题1/check_model.py
python 验证/代码/问题1/check_optimal.py
python 验证/代码/问题1/sensitivity.py
```

检查能量守恒、SOC/容量/功率及互斥、时间轴和结算相关恒等式；问题1另有KKT与强对偶检查。核验会生成报告和证据文件，但不进行四个主模型的全年重算。短期试跑可使用 `python 代码/共享/project.py smoke --problem Q2 --days 2`，它写入临时目录。

## D. 重建论文中的补充实验数据（耗时任务，本次未执行）

已有成品数据表可直接读取；若需要重新计算分位数扫描、全知下界及发布时点消融，先确保 B 的基线结果和预测缓存完整，再执行：

```bat
python 代码/共享/出图数据/run_experiments.py all
python 代码/共享/出图数据/run_issue_hours_ablation.py
python 代码/共享/project.py export
```

第一条生成表D与表F，支持 `D` 或 `F` 单独执行及 `--problem Q3` 指定问题；第二条生成表H，默认问题3与问题4-3共16个变体。补充实验中间产物写入 `图表/综合/补跑输出/`；本包只收录上述42个小型摘要与核验JSON，不收录完整中间轨迹。数小时的实验不要当作轻量导出步骤。

## 副本验证与核对范围

本包已在独立副本中验证明细还原、提交表导出、图表数据导出，并由原始附件重新预测和计算Q2、Q3、Q4-2、Q4-3的365天结果。四模型正式期费用与计划数组差均为0，逐日和逐十分钟CSV逐字节一致。问题1重新计算、可行性和最优性检查通过。独立绘图脚本生成17张结果图和8张综合图。

统一入口需要实验摘要才能运行；本包收录38个D/F实验摘要与4个C0核验JSON后，`project.py export` 与 `project.py verify` 均通过。本包没有再次运行模型，也没有修改既有结果文件。

两份提交工作簿共有4个充放电单元格位于四位小数舍入临界值，重新导出与既有工作簿最多差0.0001kWh；该差异不来自主模型数据变化。既有工作簿保留原样。

本包没有重跑表D/F/H的全部补充实验，也没有执行deep中的完整预测扰动重建。包内补充实验摘要和既有报告是既有证据；核验它们不等同于重新执行对应实验。跨环境数值一致性以固定依赖下实际运行和核验输出为准。

`文件清单_SHA256.json` 记录当前交付文件的大小和哈希，不含清单自身。
