本目录收录四个问题的正式结果、原始输入、模型源码、检验材料和图表数据生成代码。按当前交付内容整理，解压后以本目录作为运行根目录。

## 正式结果

`结果/result/` 内的 `result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx` 可直接打开。`C题/附件/附件5/` 内同名文件是官方模板，不能与正式结果混淆。

年度统计区分2025自然年365天与2025-02-01至2025-12-31正式期334天。阅读费用比较与实验表时，应使用相同统计口径。

## 环境与明细还原

使用Python 3.10（64位），在本目录执行：

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\activate
python 还原压缩明细.py
```

明细还原仅调用Python标准库，可在安装其他依赖前执行，也可双击 `先运行_还原明细.cmd`。4份 `*_physical_10min.csv.xz` 解压后恢复为原路径下的CSV；数据经SHA-256校验。此步骤不运行模型。Linux/macOS使用 `.venv/bin/python`。

## 用已交付结果生成表格与图

先还原明细，再执行：

```bat
python 代码/共享/导出result.py
python 代码/共享/project.py export
```

利用本包的结果、计划数组和预测缓存导出提交表、图表数据与图片，不进行全年优化。表D/F/H已有小型成品，export不重算这些实验。问题1的求解图与检验图需另按详细复现说明生成。

## 从原始附件重新计算

在交付包副本中删除 `代码/共享/cache/`，随后执行：

```bat
python 代码/问题1/solve_q1_ab.py
python 代码/共享/project.py run
python 代码/共享/导出result.py
python 代码/共享/project.py export
```

问题1须先计算。全年入口依次计算Q2、Q3、Q4-2、Q4-3；预测缓存由原始附件和源码重建。该操作会覆盖工作副本中的对应结果。完整实验复现还需要运行：

```bat
python 代码/共享/出图数据/run_experiments.py all
python 代码/共享/出图数据/run_issue_hours_ablation.py
python 代码/共享/project.py export
```

两条实验命令分别生成表D/F和表H，涉及多次全年计算，耗时明显长于图表导出。

## 结果核验

完成明细还原与export后执行 `python 代码/共享/project.py verify --deep`。问题1另用 `验证/代码/问题1/` 下的 `check_model.py`、`check_optimal.py`、`sensitivity.py` 检查可行性、最优性与敏感性。短期试跑使用 `project.py smoke`，产物写入临时目录。

## 数据与模型说明

原始输入均来自本包 `C题/附件/`。缓存是由输入与预测代码生成的派生产物，不是新增数据来源。问题2采用储备型LP与滚动MPC执行，问题3采用链式承诺修订与贪心执行；问题4-2、问题4-3分别在相应结构下加入因果电价预测。模型假设、结算解释、符号和时间轴见 `论文/` 中的说明。

本包已在独立副本中由原始附件重建预测并重算四个全年模型：正式期费用、计划数组、逐日和逐十分钟CSV与本包交付数据完全一致，统一 export 与 verify 入口均通过。本包未再次运行模型。

补充实验摘要及C0核验JSON为既有实验证据，本包未重跑表D/F/H全部实验。重新导出Excel时，有4个充放电单元格处于四位小数舍入边界，可能出现0.0001kWh末位差；正式结果工作簿保持原样。跨环境复现以固定依赖下的实际计算和检验输出为准。
