## 结论

| 检验 | 结果 |
|---|---|
| 电量平衡 / 储能递推残差 | 0（结果表四位小数舍入后 1e-4 量级，判据放宽到 1e-3） |
| 储电量范围 | 最低 1200、最高 10800 kWh，未越界 |
| 充放电功率 | 充电最大 5000 kW（19 个时段顶格），放电最大 4293.92 kW，未越限 |
| 同时充放电 | `min(u_t, v_t)` 恒为 0 |
| 全天能量守恒 | 左右两边都是 131765.4742 kWh，相对误差 2.2e-16 |
| 充放电量比 | Σv/Σu = 0.810000 = η_c·η_d，两个口径都成立 |
| KKT（对偶可行 + 互补松弛） | 五个变量块 x/u/v/E/w 违反数全为 0 |
| 强对偶 | 原始目标 35126.948589 元 = 对偶目标，间隙 7.3e-12 元（相对 2.1e-16） |
| 敏感性 | η 从 0.90 降到 0.85：充电效率 +1.6%、放电效率 +2.6% |
| 容量 | 10800 → 36000 kWh 才饱和；压到 6000 时费用高出 14.04% |
| 约束松绑 | 只剩日循环约束时 25207.45 元，比基准低 9919.50 元（28.24%） |

## 三条判据

- **残差容差 1e-3**：结果表 csv 只保留四位小数，残差由舍入后的数反算必然有 1e-4 量级的极小数。
  求解器内存中的残差是精确的 0，见 `solve_q1_ab.py` 的 `validate()` 输出。
- **KKT 与强对偶**：对偶值取自 `res.eqlin.marginals`，算约化成本 `rc = c − Aᵀy`，核对
  `rc>0 ⇒ 贴下界`、`rc<0 ⇒ 贴上界`；对偶目标用拉格朗日对偶函数
  `g(y) = bᵀy + Σ rc·界` 算出，与原始目标之比即强对偶证书。
  注意对偶向量长度是等式约束条数（约束A 是 290），前 144 个才对应各时段的电量平衡。
- **Σv/Σu = η_c·η_d**：只要当天首尾储电量相同，这个比值就必然等于 0.81，与电价、负载、
  容量都无关，储能递推式或效率项写错，这一行立刻不对。

## 用法

在项目根目录下执行：

```
python 验证/代码/问题1/check_model.py       # 只读 结果/问题1/ 的结果 csv
python 验证/代码/问题1/check_optimal.py     # 前一步须先跑过 solve_q1_ab.py
python 验证/代码/问题1/sensitivity.py       # 前一步须先跑过 solve_q1_ab.py
```

`check_optimal.py` 与 `sensitivity.py` 都要画检验图，因而 `from plot_style import ...`；
`plot_style.py` 位于 `代码/问题1/`，三个脚本均可直接运行。
详见 [代码/问题1/README.md](../../代码/问题1/README.md) 第七节。
