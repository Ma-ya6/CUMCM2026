# CUMCM 2026 C 题 · 微网购电与储能调度优化

小区负载 + 屋顶光伏 + 储能构成的小微电网，在全年 365 天、每 10 分钟一个决策点的
尺度上安排购电与充放电。四个问题依次递进：固定电价单日最优 → 固定电价全年因果调度
→ 多时刻发布与链式承诺结算 → 波动电价下重算。

本仓库是完整可复现的交付包：**只依赖 `C题/附件/` 下的五个原始附件**，删除
`结果/`、`图表/`、`代码/共享/cache/` 中任何生成物后，重新运行代码即可逐位复现
全部数字。

## 二、环境

Windows：

```bat
环境\创建虚拟环境.cmd
```

手动方式（任意平台）：

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Linux/macOS 用 .venv/bin/python
```

依赖：`numpy`、`pandas`、`scipy`、`scikit-learn`、`lightgbm`、`matplotlib`、`openpyxl`。
求解器用 SciPy 自带的 HiGHS（`linprog` 的 `highs`），无需额外安装。

## 三、运行

所有命令都在项目根目录下执行。

```bash
# 0) 问题1（独立单日模型；必须最先跑——第 2 步的 result1.xlsx 读它的输出，约 5 秒）
python 代码/问题1/solve_q1_ab.py

# 1) 全年计算（四问，重算并覆盖 结果/问题X/；首次会重建预测缓存，约 8–15 分钟）
python 代码/共享/project.py run

# 只跑某一问
python 代码/共享/project.py run --problem Q3
python 代码/共享/project.py run --problem Q4      # 等价于依次跑 Q4-2、Q4-3

# 2) 按 附件5 模板导出提交表格 → 结果/result/
python 代码/共享/导出result.py

# 3) 出图数据表 → 图表/数据表/，随后重绘 17 张结果图与 8 张综合图
#    若 表D/表F 尚未补算，自动跳过依赖它们的 X-1—X-4 与 Y-1（重绘 13+7 张）
python 代码/共享/project.py export

# 4) 验证（物理恒等式、时间回归、D/F 完成度）
python 代码/共享/project.py verify
python 代码/共享/project.py verify --deep        # 追加独立逻辑审计

# 5) 冒烟测试：只跑 2 天，写入临时目录，不动全年结果
python 代码/共享/project.py smoke --problem Q2 --days 2
```

问题 1 求解即上面第 0 步；它的出图与检验单独运行：

```bash
python 代码/问题1/plot_q1.py "结果/问题1/约束A（固定）_完整结果.csv" "图表/问题1/求解图/约束A（固定）"
python 代码/问题1/plot_q1.py "结果/问题1/约束B（自由）_完整结果.csv" "图表/问题1/求解图/约束B（自由）"
python 验证/代码/问题1/check_model.py      # 可行性 + 守恒 + Σv/Σu
python 验证/代码/问题1/check_optimal.py    # KKT + 强对偶证书
python 验证/代码/问题1/sensitivity.py      # 参数敏感性与约束松绑
```

### 一键运行

各问题文件夹下有 `一键运行.cmd`，等价于对该问题执行 `project.py run`：

| 脚本 | 等价命令 |
|---|---|
| `代码/问题1/一键运行.cmd` | `python 代码/问题1/solve_q1_ab.py` |
| `代码/问题2/一键运行.cmd` | `python 代码/共享/project.py run --problem Q2` |
| `代码/问题3/一键运行.cmd` | `python 代码/共享/project.py run --problem Q3` |
| `代码/问题4/问题4-2/一键运行.cmd` | `python 代码/共享/project.py run --problem Q4-2` |
| `代码/问题4/问题4-3/一键运行.cmd` | `python 代码/共享/project.py run --problem Q4-3` |

### 可复现性

- 预测层在 `代码/共享/cache/rebuilt.npz` 缓存，缓存键是**全部源码 + 全部附件**的
  SHA-256 指纹；源码或附件任何一处变动都会自动失效重建。
- 删除 `代码/共享/cache/`、`结果/`、`图表/` 后重跑，得到的数字与原值逐位一致。
- 全年重算会断言：年终实际 SOC 回到 6000 kWh、物理审计各项违例为 0、能量恒等式
  误差 < 1e-5；任一不满足即抛错终止，不会写出"看起来对"的结果。

按重建代价分三档，删除产物后对应重跑：

| 产物 | 重建方式 | 代价 |
|---|---|---|
| `结果/问题X/`、`结果/result/`、`结果/汇总/`（冻结数字、全年费用汇总、表G）、`图表/数据表/`（表A/B/C、月度、预测误差等）、`图表/问题2…问题4/`、`图表/综合/` 的 X-1…X-4 与 Y-1…Y-8 | `project.py run` → `导出result.py` → `project.py export` | 全年重算，约 8–15 分钟 |
| `图表/数据表/表D_*`、`表F_*`、`结果/汇总/表F_*`，以及中间产物 `图表/综合/补跑输出/` | `python 代码/共享/出图数据/run_experiments.py all`（约 38 次全年仿真，最贵），再跑 `project.py export` | 数小时，可断点续算 |
| `结果/问题1/`、`图表/问题1/`、`验证/数据/` 的检验表 | `python 代码/问题1/solve_q1_ab.py`，再按上一节的问题1 命令出图与检验 | 约 5 秒 |

图表逐张的作用与重建方式见 [图表/图表说明.md](图表/图表说明.md)，其中 34 张图全部可由
本仓库代码重建。

## 四、模型要点

| | 决策发布 | 优化模型 | 结算规则 |
|---|---|---|---|
| 问题1 | 单日一次 | 纯 LP，约束 A（端点固定）/ B（端点自由） | 固定电价 |
| 问题2 | 00:00 一次 | 因果预测 + 分位数安全余量 R + 储备型 LP | 固定电价，紧急购电 5 倍罚 |
| 问题3 | 00/06/12/18 | 链式承诺增量 MILP | 下调 0.5 倍违约、上调 1.5 倍超购 |
| 问题4-2 | 00:00 一次 | 同问题2，电价改因果预测 | 同问题2，波动电价 |
| 问题4-3 | 00/06/12/18 | 同问题3，电价改因果预测 | 同问题3，波动电价 |

储能：容量 12000 kWh，SOC 运行区间 1200–10800 kWh，充放电功率上限各 5000 kW，
充放电效率各 0.90，初始与年终 SOC 均为 6000 kWh。**不设日终 SOC 等式约束**，
年终由最后一天的可达性保护实现。

两套时间轴：物理轴 `i`（1..144，`I_{d,1}` 为 00:00—00:10）用于平衡与结算；附件 5
计划轴 `j`（1..144，`J_{d,1}` 为 00:10—00:20）用于提交表格，映射
`J_{d,j} = I_{d,j+1}`、`J_{d,144} = I_{d+1,1}`。

正式输出期为 2025-02-01 至 2025-12-31 共 334 天；同时给出 2025 自然年 365 天口径。

模型细节见 [论文/模型介绍.md](论文/模型介绍.md)，方法讨论与评价见
[论文/方法说明与模型评价.md](论文/方法说明与模型评价.md)。

## 五、数据来源

全部输入来自 `C题/附件/` 下的五个原始附件，不含任何外部数据、不含任何继承的结果
缓存。代码中所有路径均为项目内相对定位，附件目录通过自 `代码/` 向上逐级查找
`C题/附件/` 获得，因此整个仓库可以任意移动、可被他人直接克隆运行。
