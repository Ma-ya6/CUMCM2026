# 图表说明

`图表/` 下共 **34 张 PNG**，另有 `图表/数据表/` 下的出图用 CSV。本文件逐张写明每张图
**是干什么用的**（回答什么问题、看图时该看什么），以及它由哪个脚本生成、当前能否重建。

单位约定：文件名/列名里 `*_kw` 是功率，`*_kwh` 是十分段电量；同轴比较时电量乘 6 变成功率。
时间口径：默认 334 天正式期（2025-02-01—12-31），另有 365 天自然年口径在
`图表/数据表/自然年365天/`，两套不可混用。

| Y-8 | 负荷光伏净负荷概览.png | 全年负荷、光伏、净负荷的月度均值曲线与净负荷热力图。给出四个问题共同的物理背景，是其余所有图的底图。 |

## 六、可重建性一览

34 张图全部可由本仓库代码重建。删除 `图表/` 后按根 README 的三档顺序重跑即可。

| 图组 | 张数 | 生成脚本 | 重建方式 |

| `综合/X-1…X-4` | 4 | `代码/共享/出图数据/plot_result_figures.py` | `project.py export`（表 D、表 F 需先跑 `run_experiments.py`） |
| `问题2` | 4 | 同上 | `project.py export` |
| `问题3` | 5 | 同上 | `project.py export` |
| `问题4` | 4 | 同上 | `project.py export` |
| `问题1/求解图` | 6 | `代码/问题1/plot_q1.py` | 先 `solve_q1_ab.py`，再按 README 的两条命令行出图 |
| `问题1/检验图` | 3 | `验证/代码/问题1/check_optimal.py`、`sensitivity.py` | 直接运行这两个脚本 |
| **合计** | **34** | | |
