# C 题 问题一：典型日微网购电与储能调度

本目录是问题一的完整交付包，包含代码、图表、结果文件与论文。

---

## 一、问题一句话

给定典型日 144 个 10 分钟时段的电价、小区负载与光伏预测（附件 1），
在储能的功率、容量与效率约束下，制定购电与充放电计划，使全天购电费用最小，
并要求储能设备在 0:00 与 24:00 的储电量相同。

## 三、两个模型的区别

两份代码除**一条约束**外逐字相同，差异只在日循环的端点口径：

| | 模型 A | 模型 B |
|---|---|---|
| 日循环约束 | $E_0=E_{144}=6000$ | $E_0=E_{144}$，取值自由 |
| 依据 | 附录 1 给出的初始储电量 6000 kWh | 题面只要求两端相等 |
| 优化得到的循环储电量 | 6000 kWh | 8550 kWh |
| 全天购电费 | **35126.9486 元** | **35118.5986 元** |

模型 A 的任意可行解在模型 B 中都可行，所以 B 的可行域更大、最优费用必然不高于 A。
实测两者相差 **8.35 元（0.024%）**，对结论没有影响。

## 五、模型要点

**属于线性规划。** 决策变量是每段的购电量 $x_t$、充电量 $u_t$、放电量 $v_t$、
弃光量 $w_t$（均为功率 kW），状态量是储电量 $E_t$（kWh，共 145 个）。
目标 $\min\sum_t c_tx_t\Delta t$ 与全部约束都是线性的，
用 HiGHS 求解，**全局最优、毫秒级**。

**不需要整数变量。** 充放电往返效率 $\eta_c\eta_d=0.81<1$，
同一时段既充又放只会凭空增加损耗，最优解自动满足 $\min(u_t,v_t)=0$。

**储能的钱赚在哪里。** 凌晨与正午电价低时充电，傍晚 18:00–21:00 电价最高时放电顶负载。
全天购电量比无储能时略高（因为往返有 19% 损耗），但购电费显著下降：
从 48052.05 元降到 35126.95 元，**节省 26.9%**。

## 七、图表是怎么画出来的

五张图由 `plot_q1.py` 生成，**没有画图软件，全部是 matplotlib 代码**，
你可以随意修改。它从结果 csv 读数据，不重新求解模型，
所以改图不用等求解，几秒钟就能出新图。

### 用法

```
python plot_q1.py <结果csv> <输出目录> <标题后缀>
```

例如重新生成模型 A 的五张图：

```
python plot_q1.py 模型A_固定6000\results\问题一_完整结果.csv 模型A_固定6000\figures "（口径A：两端固定 6000 kWh）"
```

### 五张图分别画什么

| 图 | 内容 | 数据来源 |
|---|---|---|
| 图 1 | 电价（左轴）、负载与光伏（右轴） | `c_t`、`L_t`、`P_t^fc` |
| 图 2 | 净负荷填充、计划购电量曲线、电价虚线 | `净负荷`、`x_t`、`c_t` |
| 图 3 | 储能 SOC 轨迹与上下限 | `E_t`（145 个点） |
| 图 4 | 逐时段充电（正）/ 放电（负）电量柱状 | `u_t`、`v_t` |
| 图 5 | 有储能与无储能的购电量对比，并填充差异区 | `x_t`、`净负荷` |

### 可以改哪些地方

**颜色。** 脚本里用的是 Tableau 色系：`#4C78A8` 蓝、`#E45756` 红、
`#54A24B` 绿、`#F58518` 橙、`#B279A2` 紫。全局替换即可换配色。

**图幅与清晰度。** 每张图的 `figsize=(10, 4.6)` 控制宽高（英寸），
`dpi=160` 控制分辨率；投稿要求更高清晰度就调到 300。

**字体。** 顶部 `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]`
指定中文字体；换电脑若显示方块，把本机已有字体名填进来即可。

**增删图。** 每张图是一段独立的代码块，用 `# ---- 图N ...` 标注，
整段注释掉或删掉就不会输出；想加新图，复制任意一段改数据列即可。

**改标题。** 命令行第三个参数会拼到所有图的标题末尾，
方便同一套脚本给不同口径出图。
