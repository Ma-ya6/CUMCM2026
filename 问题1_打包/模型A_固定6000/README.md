# 模型 A · 日循环两端固定 6000 kWh

## 一句话

把附录 1 给出的初始储电量 6000 kWh 作为日循环的共同端点（$E_0=E_{144}=6000$），
生成可直接执行的典型日购电与充放电计划。

## 文件

| 文件 | 说明 |
|---|---|
| `solve_A_fixed6000.py` | 求解代码，单文件自包含 |
| `论文_模型A.md` | 论文正文（含表 1、表 2、检验与灵敏度） |
| `figures/` | 图 1 ~ 图 5 |
| `results/result1.xlsx` | 按题目模板生成的结果文件 |
| `results/问题一_完整结果.csv` | 逐时段明细（145 行 × 14 列） |
| `results/预处理表.csv` | 数据预处理表（含净负荷） |

## 运行

```
python solve_A_fixed6000.py
```

依赖：`pandas`、`numpy`、`scipy`、`openpyxl`。原附件只读。

## 调度规律

0:00–4:00 电价最低，全额充电 4500 kWh；6:00–8:00 电价升至 0.86–0.99 元/kWh，
放电 6365.84 kWh 顶负载；正午光伏富余时段继续充电；
16:00–20:00 电价最高（1.2–1.4 元/kWh）放电 5780.13 kWh；
22:00 后电价回落，再充电补回储电量。
