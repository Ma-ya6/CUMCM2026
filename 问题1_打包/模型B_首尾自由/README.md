# 模型 B · 日循环两端相等、取值自由

## 一句话

只要求 $E_0=E_{144}$、共同取值交给优化决定，用于考察储能容量的充分套利潜力。
优化给出的循环储电量为 8550 kWh。

python solve_B_free_cycle.py

依赖：`pandas`、`numpy`、`scipy`、`openpyxl`。原附件只读。

## 与模型 A 的关系

模型 A 的可行域是本模型的子集，因此本模型的最优费用必然不高于模型 A。
实测两者相差 8.35 元（0.024%）：购电量、充放电总量、往返损耗完全一致，
差别只在充电的时间分布——凌晨 0:00–4:00 的充电量由 4500 降到 1666.67 kWh，
20:00–24:00 由 5333.33 升到 8166.67 kWh。

## 使用提示

本模型的计划假定循环起点为 8550 kWh，而附录 1 给出的实际初始电量是 6000 kWh，
执行前需先补足 2550 kWh 的差额。若论文需要给出可直接执行的计划，
建议以模型 A 为主结果，本模型作为灵敏度分析。
